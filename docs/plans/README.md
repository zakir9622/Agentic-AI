# Lookbook planning docs

No active plan exists here right now. The one prior plan directory,
`lookbookweb-exact-ui-parity/`, was removed in this documentation pass: it was already
self-documented as superseded (its own `PLAN.md` recorded that the 5-item dock + Create FAB it
called for was rejected by direct user request back in v3.1.4), and the app's actual direction
since then — the GoogleLookBookUI cross-repo port and the generation-audit follow-through — went
a different way entirely, with no relationship to that plan's remaining phases. Its still-open,
non-UI carried-forward items (real on-device benchmark numbers, a live Appium device run, QNN
execution-provider packaging, an ONNX NSFW classifier, an iOS target) are preserved in
[`../PROJECT_HISTORY.md`](../PROJECT_HISTORY.md#known-gaps--carried-forward-open-items) rather
than lost.

For what has actually shipped and why, see [`../PROJECT_HISTORY.md`](../PROJECT_HISTORY.md).
When a new plan starts, put it in a new directory here following the same pattern (a `PLAN.md`
with the full detail, a short `README.md` pointing to it) and update this table.
